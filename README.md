# Snake Game

## Description

- This is a simple snake gameplay for testing and just for fun :v
- Languages: html, css, js.
- Apply: basic OOP, module structure.

## How to play

- Use arrow keys (↑, ↓, ←, →) for moving.
- To start the game, pressing any arrow keys.
- By default, the snake starting direction will be to the right.
